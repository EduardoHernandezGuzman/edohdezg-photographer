# Fuentes auto-hospedadas

Archivos woff2 (subset latin) descargados de [Google Fonts](https://fonts.google.com) para eliminar dependencias externas en tiempo de ejecución.

| Familia      | Pesos              | Archivo                        | Licencia |
| ------------ | ------------------ | ------------------------------ | -------- |
| Oswald       | 400                | `oswald-latin-400.woff2`       | OFL 1.1  |
| Merriweather | 400-700 (variable) | `merriweather-latin-var.woff2` | OFL 1.1  |
| Bebas Neue   | 400                | `bebas-neue-latin-400.woff2`   | OFL 1.1  |

Las tres familias se distribuyen bajo la [SIL Open Font License 1.1](https://openfontlicense.org).

Las declaraciones `@font-face` están en `css/fonts.css`.
